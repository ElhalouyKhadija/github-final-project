# Simple Interest Calculator

## Project Description
This project is a simple interest calculator built using a Bash script.  
It allows users to calculate simple interest based on three inputs: principal, rate of interest, and time period.

---

## Formula Used
Simple Interest = (Principal × Rate × Time) / 100

---

## Input Fields
The script asks the user to enter:

- Principal amount
- Rate of interest
- Time period (in years)

---
